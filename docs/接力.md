## 已知的坑（会重复踩）

- CubeMX 点 Generate Code 后如果卡很久，是在后台下载/解压固件包（100MB 量级），**不是死机，别关**
- 引脚忘了填 User Label，所以 `main.h` 的 `Private defines` 是空的，写代码要自己补宏
- 开了两个 CubeMX 实例会报 `Updater is already in use`，`taskkill /F /IM javaw.exe` 全杀后重开
- CubeMX 启动时如果 MCU 列表 0 项，那是器件库还没加载完，**重启 CubeMX**
