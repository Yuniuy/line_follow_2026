## 四、开发约定

1. **非阻塞**：OLED 刷新、串口发送、蜂鸣器都必须非阻塞，禁止在循线循环里用 `HAL_Delay`
2. **供电分离**：电机走电池电压，主控走降压后 5V/3.3V，必须共地
3. **提交纪律**：赛题要求「每周至少一次有效提交」，每次完成一个可验证的小功能就 commit
4. **提交信息格式**：`[模块] 做了什么`
   - 例：`[oled] 实现主菜单显示与按键移箭头`
   - 例：`[uart] 支持 GET A 查询，修复负数解析`
